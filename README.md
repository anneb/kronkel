# Kronkel

Een territorium-veroveringsspel in de browser, te spelen met je vinger (of pijltjestoetsen/WASD).

**Speel online:** https://anneb.github.io/kronkel/

## Spelregels
- Sleep met je vinger in een richting om te bewegen; loslaten = stoppen.
- Verlaat de rand om een lijn te trekken en sluit hem weer aan op de rand om dat stuk veld te veroveren.
- Verover 75% om naar het volgende level te gaan.
- Pas op voor de **Kronkel**: raakt hij je lijn, dan ben je een leven kwijt.
- **Vonken** jagen langs de randen.
- Sta je stil tijdens het tekenen, dan brandt er een **lont** langs je lijn naar je toe.
- 🔊/🔇 of toets `M` zet het geluid aan/uit.

Eén HTML-bestand, geen dependencies.
